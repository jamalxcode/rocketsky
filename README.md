# RocketSky

A browser remake of Atari's 1980 arcade game **Missile Command**, in a single HTML file with no dependencies.

Open `index.html` in a browser and click to start.

## Features
- Pixel-art rendering with CRT scanlines
- Flickering chain-reaction explosions and screen flash on city hits
- MIRVs, bombers, satellites and smart bombs in later waves
- Three bases with 10 missiles each (center base fires fastest), LOW / OUT warnings
- Wave intro, bonus tally, bonus cities every 10,000 points, and the "THE END" finale
- Sound effects synthesized live with the Web Audio API

## Controls
| Input | Action |
| --- | --- |
| Mouse / tap | Aim and fire from the nearest base |
| A / S / D | Fire from left / center / right base |
| P or Esc | Pause |
| M | Sound on / off |
